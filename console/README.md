# Tipos de datos de Python — desde cero

Orden recomendado para estudiar:

1. `integer.py` — números enteros
2. `float.py` — números decimales
3. `string.py` — texto
4. `boolean.py` — verdadero/falso
5. `list.py` — listas
6. `tuple.py` — tuplas
7. `set.py` — conjuntos
8. `dictionary.py` — diccionarios
9. `none.py` — ausencia de valor
10. `conversion.py` — conversión entre tipos
11. `practice.py` — práctica integradora

## Cómo usarlos

Abre cada archivo y ejecuta:

```bash
python nombre_del_archivo.py
```

Cada archivo contiene:
- explicación breve
- ejemplos
- comentarios
- ejercicios al final

La idea es aprender un tipo de dato a la vez antes de pasar al siguiente.
